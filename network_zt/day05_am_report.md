- (한 줄) 고객에게 보낼 답을 한 문장으로 적어 주세요.

## 4교시 · 구역 규칙 코드

### 문제 4-1 · 규칙 판정 코드 읽고 설명하기

- (가) 함수 `default_policy` · `match_rule` · `judge` 가 각각 무엇을 하는지 적어 주세요.
  - 쓸 내용: 「default_policy: … / match_rule: … / judge: …」 함수마다 자유롭게
  - 답: default_policy: 요청과 맞는 규칙이 없을 때 허용할지 차단할지 정합니다. / match_rule: 규칙 한 줄이 요청의 출발 구역·도착 구역·포트와 모두 맞는지 확인합니다. / judge: 규칙을 위에서부터 확인해 처음 맞는 규칙의 동작과 번호를 돌려주고, 하나도 맞지 않으면 기본 정책 결과와 번호 0을 돌려줍니다.
- (나) `judge` 가 리턴하는 값 두 개는 무엇이고, 어느 줄이 만드나요?
  - 쓸 내용: 「값 ①: … / 값 ②: … / 만드는 줄: …」
  - 답: 값 ①: 동작(`permit` 또는 `deny`) / 값 ②: 적용된 규칙 번호(기본 정책이면 0) / 만드는 줄: 맞는 규칙이 있으면 `return rule[4], rule[0]`, 없으면 `return default_policy(src, dst), 0`
- (다) 🔍 `judge` 의 `for` 는 맞는 규칙을 찾으면 바로 `return` 합니다. 같은 요청에 규칙이 둘 이상 맞는다면 어느 규칙이 적용되나요? 왜 `return` 으로 바로 끝내도록 만들었나요?
  - 쓸 내용: ① 규칙이 둘 이상 맞을 때 적용되는 규칙 ② 방화벽이 「첫 번째로 맞는 규칙」을 쓴다는 점과 이어서 `return` 으로 바로 끝내는 이유
  - 답: 규칙 목록에서 위에 있는, 즉 가장 먼저 맞는 규칙이 적용됩니다. 방화벽이 첫 번째로 맞는 규칙의 동작을 사용하므로 그 결과와 규칙 번호를 돌려준 뒤 바로 끝내고, 아래 규칙이 결과를 덮어쓰지 않게 합니다.

### 문제 4-2 · 허용 포트 목록 함수 채우고 흐름 그리기

- (가) 채운 `allowed_ports` 함수를 붙여 넣고, 실행해서 나온 출력 네 줄을 적어 주세요.
  - 쓸 내용: ① 채운 함수 ② 출력 네 줄
  - 답:

```
def allowed_ports(src, dst, ports):
    result = []
    for port in ports:
        action, no = judge(src, dst, port)
        if action == "permit":
            result.append(port)
    return result

[443]
[445]
[22, 80, 443, 445, 3389]
[]
```
- (나) `judge` 함수의 흐름을 ASCII 도식(상자 · 화살표)으로 그려 아래 코드 블록에 넣어 주세요.
  - 쓸 내용: 코드 블록 안에 ASCII 도식을 직접 그리기(상자 안은 영어 · 숫자)
  - 답:

```
START
  |
  v
[ take next rule from RULES ]
  |
  v
[ match_rule(rule, src, dst, port)? ]
  | yes
  v
[ RETURN action, rule number ]
  |
  v
 END

If no:
[ more rules? ]
  | yes
  +----> [ take next rule from RULES ]
  |
  | no
  v
[ RETURN default_policy, 0 ]
  |
  v
 END
```

- (다) 🔍 `allowed_ports` 에서 `result = []` 를 `for` 위에 두는 이유는 무엇인가요? `for` 안에 두면 어떻게 되나요?
  - 쓸 내용: ① `result = []` 를 `for` 위에 두는 이유 ② `for` 안에 두면 달라지는 점
  - 답: 포트를 하나씩 검사하면서 허용된 포트를 모두 같은 리스트에 모으기 위해 `for`문 전에 한 번만 빈 리스트를 만듭니다. `for` 안에서 만들면 매번 목록이 비워져 마지막 포트의 결과만 남고, 앞에서 찾은 허용 포트가 사라집니다.
- (한 줄) 고객에게 보낼 답을 한 문장으로 적어 주세요.
  - 쓸 내용: 고객이 바로 읽을 수 있는 한 문장(요구사항이 지켜졌는지)
  - 답: 확인 결과 인터넷에서 DMZ로는 443만, DMZ에서 내부망으로는 445만 허용되고 내부망의 DMZ 접속은 허용, 인터넷에서 내부망으로의 접속은 모두 차단되어 요구사항과 일치합니다.
- 이 교시에서 새로 알게 된 것 하나를 적어 주세요.
  - 쓸 내용: 자유롭게
  - 답: 규칙에 맞는 포트만 리스트에 차곡차곡 모으면 여러 포트의 허용 여부를 한 번에 확인할 수 있습니다.
