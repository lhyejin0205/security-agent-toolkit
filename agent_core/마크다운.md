# VS Code 마크다운 기본 단축키
• 미리보기 열기: Ctrl + Shift + V (새 탭) 또는 Ctrl + K V (측면 분할)

• 굵게: Ctrl + B

• 기울임꼴: Ctrl + I

• 자동 완성: Ctrl + Space

# 주요 마크다운 문법
• 제목 (Headers): #부터 ######까지 사용 (H1~H6)

• 기본 텍스트 서식:

	• 굵게: **텍스트** 또는 __텍스트__

	• 기울임: *텍스트* 또는 _텍스트_

	• 취소선: ~~텍스트~~

• 목록 (Lists):

	• 순서 없는 목록: -, *, + 중 하나 사용
	• 순서 있는 목록: 1., 2. 등 번호 사용
	• 체크박스: - [ ] (미완료), - [x] (완료)

• 인용문 (Quote): > 기호 사용

• 코드 블록:

	• 인라인 코드: `코드`
	• 여러 줄 코드: ```언어명 ... ```

• 링크와 이미지:

	• 링크: [표시할 텍스트](주소)
	• 이미지: ![대체 텍스트](이미지주소)
